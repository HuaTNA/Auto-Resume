# Birch icon set

Extracted from the Figma Make download `Design Icon Set with Birch`.

The original download stored all nine icons as inline React SVG elements in `src/app/App.tsx`. This directory contains standalone, optimized SVG assets while preserving the original 64x64 geometry and palette.

## Palette

- Birch ink: `#26332F`
- Lenticel: `#E1EAE5`

## Icons

- `tree.svg` — 树 / Tree
- `leaf.svg` — 叶 / Leaf
- `grove.svg` — 林 / Grove
- `bark.svg` — 皮 / Bark
- `catkin.svg` — 絮 / Catkin
- `bud.svg` — 芽 / Bud
- `growth-ring.svg` — 纹 / Growth Ring
- `branch.svg` — 枝 / Branch
- `winter.svg` — 雪 / Winter

Use these as brand or decorative icons. They are intentionally filled and organic, so they should not replace functional UI symbols such as search, settings, or navigation arrows.
